## Qanday o'rganiladi?

Har bir fayl quyidagi tuzilmaga ega:

- `❌ YOMON (BAD)` — nima **qilmaslik** kerak, misol bilan
- `✅ YAXSHI (GOOD)` — to'g'ri yondashuv
- `🚀 YANADA YAXSHIROQ` — eng yaxshi amaliyot (best practice)
- `📌 Xulosa` — mavzuning asosiy fikrlari
